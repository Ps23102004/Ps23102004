# Hi, I'm Parth Singh

I build **local-first AI tools** -- software that respects your privacy by keeping your data on your machine.

## What I'm building

- [**homeground**](https://github.com/Ps23102004/homeground) -- type your home address, ride a longboard down your own street: real OpenStreetMap data rebuilt as a playable 3D level
- [**fairdeal**](https://github.com/Ps23102004/fairdeal) -- honest "is this fair?" verdicts on rent, leases, college ROI, and contracts, checked against real benchmark data
- [**VisaRadar**](https://github.com/Ps23102004/VisaRadar) -- evidence-backed H-1B sponsorship checks from real DOL filing history, not another job board
- [**memory-audit**](https://github.com/Ps23102004/memory-audit) -- see everything AI has stored about you, across ChatGPT, Claude, and Cursor
- [**smallprint**](https://github.com/Ps23102004/smallprint) -- local-first CLI that flags concerning clauses in contracts
- [**llm-ladder**](https://github.com/Ps23102004/llm-ladder) -- cascade router across tiered local LLMs that only escalates to a bigger model when confidence drops

Plus a workbench of agent-observability tools: `ctxlens`, `squeeze`, `memgc`, `membench`, `agentvcr`, `agentdiff`, `agentops-console`.

## Stack

Python · TypeScript · FastAPI · Three.js / WebGPU · Ollama & local LLMs · scikit-learn
